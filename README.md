# 🌤️ Weather Forecasting Site

A beginner-friendly and responsive weather web application built with **HTML, CSS, and JavaScript**. It provides real-time weather information for any city around the world, including temperature, humidity, wind speed, and weather conditions.

---

## ✨ Features

- 🔍 **City Search:** Search weather details for any city worldwide.
- 🌡️ **Temperature Display:** Shows current temperature in Celsius.
- 💧 **Humidity & Wind Speed:** Displays key meteorological metrics.
- 🎨 **Responsive Design:** Works smoothly on desktop, tablet, and mobile devices.
- ⚡ **Real-time Data:** Fetches live data using the OpenWeatherMap API.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **API:** [OpenWeatherMap API](https://openweathermap.org/api)
